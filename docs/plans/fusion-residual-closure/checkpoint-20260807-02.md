# Checkpoint 02: v14 residual closure locally complete

## Root cause closed

The recommendation resolver treated Fusion as a mandatory absolute expected-return owner. A missing, rejected, incompatible, or non-primary Fusion artifact returned no expected return even when canonical L4 was valid. The next gate converted that to risk abstention, so the sparse allocator saw no eligible positive edges.

## Final production contract

- Canonical L4 is the base expected return.
- Fusion can only add a validated residual adjustment.
- `final_expected_return = l4_base_expected_return + fusion_residual_adjustment`.
- Missing/rejected/incompatible Fusion means `overlay_status=abstained` and adjustment `0`.
- Missing/invalid L4 means `action_gate=canonical_l4_required` and remains fail-closed.
- OnlinePortfolioBandit controls allocator parameters only.
- `sparse_tangent_inverse_risk` remains final selection and weight owner; there is no forced fill or top-k fallback.
- S12 execution experts are shadow diagnostics only and cannot affect v14 serving or promotion.

## Evidence and promotion

- Artifact contract and feature semantic version are v14 across Python and Worker.
- Residual labels use canonical five-session net return minus legal point-in-time L4 EV.
- Challenger and base use the same OOS rows, dates, label, and cost contract.
- Primary comparison requires non-inferior correlation/spread LCB90, positive top five-session EV LCB90, regime safety, stable walk-forward, and no joint deterioration across the latest two OOS dates.
- Multiple strategy searches require an approved White Reality Check, Hansen SPA, or Deflated Sharpe correction when more than one variant was searched.
- 20 total dates / 5 OOS dates is the validation floor; 40 total dates / 10 OOS dates is the primary floor. These are operational evidence floors derived from the 75/25 temporal split, not universal industry constants.

## Automation and UI closure

- Worker serving state uses canonical L4 readiness as the hard action boundary.
- Fusion pointer/artifact failure and allocator snapshot freshness are warnings when L4 is valid.
- L4 pointer/artifact failure and L4 OOF freshness remain hard alerts.
- Evidence UI now shows residual OOS skill, paired deltas against same-contract L4, recent deterioration, and multiple-testing status.
- Sector/market coverage is diagnostic unless the fitted residual model actually uses those features.
- S12 experts are explicitly labeled shadow diagnostic with no promotion effect.
